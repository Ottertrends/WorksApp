## Security/behavior limits to keep explicit

- Exact-action receipt deduplication is per job. WhatsApp has durable provider deduplication. Web callers may supply an Idempotency-Key; the current frontend does not, so retries from a new browser request are not universally deduplicated.
- Uncertain outcomes block further work for that workspace until reviewed. This favors avoiding duplicate billing/deletion over silently repeating an action.
- Workspace serialization helps usage limits, but this is not a separate atomic billing reservation system across every other product endpoint.
- Cost estimates are null unless model prices are configured. Nested tool model costs are not yet fully represented by the main-run metric.
- The broad tool authorization wrapper is a security improvement, not a claim that every web API/RLS policy in the entire product has been audited.
